Display and UI type both use those Geist files. The previous Cursor Gothic files were all-rights-reserved and were removed so this package can be redistributed under MIT.

The OG image uses Agent Command Center branding. Third-party SVG/vendor notices remain applicable. Maintainer attribution to aipieksel does not claim authorship of third-party assets.
